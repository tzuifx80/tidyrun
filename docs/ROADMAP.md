# Roadmap (post v0.1)

TidyRun v0.1 is feature-frozen. Priorities after early-user feedback:

1. Broader real-agent measurements across providers
2. Investigate token/turn amplification in live sessions
3. Additional structured output parsers (Playwright, Docker, etc.)
4. Stronger provider integrations where hooks are stable
5. Cross-platform edge cases (Windows/Linux/macOS)
6. Verify or demote experimental rules based on session data

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for contribution areas.
